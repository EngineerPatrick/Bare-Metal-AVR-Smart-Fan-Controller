# Bare-Metal-AVR-Smart-Fan-Controller
A bare-metal embedded C project for the ATmega328P / Arduino Uno R3.  The firmware reads temperature from a BME280 sensor, lets the user configure a fan-speed curve using push buttons and a rotary encoder, drives a 4-wire PWM fan, measures tachometer feedback, and displays temperature/RPM values on an SSD1306 OLED.
